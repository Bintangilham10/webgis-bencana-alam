SIGAP Bencana· Sistem Informasi Geospasial Antisipasi dan Peringatan

Semua informasi bencana Indonesia, di satu peta.

Gempa terkini, status gunung api, peringatan hujan BMKG, dan indikasi 3 hari untuk 514 kabupaten/kota, dari data terbuka BMKG, BNPB, dan PVMBG.

Lihat fiturnya
  • – kab/kota berindikasi Waspada ke atas
  • – gempa dirasakan/M ≥ 5 dalam 7 hari
  • – gunung api Siaga ke atas
  • – peringatan hujan BMKG

Tangkapan layar aplikasi, 30 Sep 2026 · memuat data terbaru…

Fitur

Empat hal yang bisa Anda lakukan

  1. 01

    Lihat situasi seluruh Indonesia

    Ikhtisar merangkum gempa 24 jam, gunung api berstatus tinggi, peringatan hujan, dan kab/kota berindikasi. Di peta: gempa BMKG (M ≥ 5 dan gempa dirasakan) tiap menit, 69 gunung api MAGMA, dan sesar aktif.

    Memuat data…

  2. 02

    Cek indikasi 3 hari tiap kab/kota

    Tiap 12 jam, prakiraan hujan di ribuan titik pantau dipertemukan dengan zona bahaya InaRISK. Hasilnya level Normal sampai Awas untuk hujan lebat, banjir, dan tanah longsor, dengan peringatan resmi BMKG di sebelahnya.

    Memuat data…

  3. 03

    Pantau peringatan hujan BMKG

    Peringatan dini curah hujan tinggi BMKG per dasarian digambar di batas kab/kota, lengkap dengan tautan ke keterangan resmi. Hujan terkini dari satelit NASA juga tersedia sebagai lapisan.

    Memuat data…

  4. 04

    Cek risiko satu titik

    Cari desa, pakai GPS, atau klik kanan di peta. SIGAP menjalankan 11 pengecekan sekaligus: indikasi 3 hari, lima indeks bahaya BNPB, jarak ke sesar aktif dan gunung api, gempa sekitar, lereng, dan riwayat longsor.

    Contoh: Lembang, Bandung Barat · 1,4 km dari Sesar Lembang

Cara kerja

Dari data mentah ke indikasi, otomatis

Memuat run terakhir…

  1. 1

    Kumpulkan

    Server mengambil data resmi secara berkala, tanpa campur tangan manusia.

    Gempa tiap 1 menit · gunung api tiap 30 menit · hujan tiap 12 jam

  2. 2

    Gabungkan

    Di PostGIS, prakiraan hujan di tiap titik pantau dipertemukan dengan zona bahaya InaRISK.

    3.221 titik pantau di 514 kab/kota

  3. 3

    Nilai

    Aturan terbuka memberi level dari hujan harian tertinggi dan kelas bahaya di titik itu.

    Satu berkas: rules.json v0.2

  4. 4

    Tampilkan

    Hasilnya muncul di peta, Ikhtisar, dan cek risiko, dengan peringatan resmi di sebelahnya.

    Saat ini: – Awas · – Siaga · – Waspada · – Normal

Aturan v0.2 belum dikalibrasi; ketepatannya sedang diuji dalam riset SIGAP-L.

Cara memakai

  1. Cari tempat di kotak pencarian atau tekan Lokasi saya.
  2. Baca profil risiko: status 3 hari ke depan, tingkat bahaya, dan jarak ke sesar serta gunung api.
  3. Warna kab/kota di peta adalah indikasi SIGAP 3 hari. Klik wilayahnya untuk rincian hujan lebat, banjir, dan longsor.
  4. Nyalakan peta rawan banjir, longsor, atau bahaya lain di tab Lapisan.

Tentang SIGAP Bencana

SIGAP Bencana menggabungkan data terbuka BMKG, BNPB, PVMBG, dan PuSGeN dalam satu peta untuk membantu warga memahami risiko bencana di lokasinya. Dibuat sebagai Tugas Besar mata kuliah Teknologi Pemetaan Berbasis Web, Telkom University.

Informasi di sini bukan peringatan resmi. Untuk keputusan keselamatan, ikuti BMKG, MAGMA/PVMBG, dan BNPB/BPBD setempat.

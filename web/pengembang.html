API SIGAP Bencana

Data yang tampil di peta SIGAP, dalam bentuk JSON untuk aplikasi Anda: gempa, level gunung api, peringatan dini cuaca, indikasi 3 hari, dan notifikasi langsung.

Layanan riset mahasiswa, bukan peringatan resmi. Untuk keputusan keselamatan, ikuti BMKG, MAGMA/PVMBG, dan BNPB/BPBD setempat.

Dapatkan kunci

Tiap aplikasi memakai kuncinya sendiri. Kunci langsung terbit setelah formulir dikirim, dengan kuota 5.000 permintaan per hari.

Hanya dipakai untuk menghubungi Anda soal kunci ini.

Kunci Anda Simpan sekarang. Kunci tidak disimpan di server dan tidak bisa ditampilkan lagi. Contoh di bawah sudah memakai kunci ini.

Panggil API

Kirim kunci di header X-API-Key pada tiap permintaan. Jawabannya JSON; data berlokasi berbentuk GeoJSON.

curl

curl -H "X-API-Key: KUNCI_ANDA" "https://alamat-server/api/v1/earthquakes?days=7"

JavaScript (Node.js)

const res = await fetch('https://alamat-server/api/v1/earthquakes?days=7', {
  headers: { 'X-API-Key': 'KUNCI_ANDA' },
});
const gempa = await res.json(); // GeoJSON FeatureCollection
console.log(gempa.features.length, 'gempa; sisa kuota', res.headers.get('X-RateLimit-Remaining'));

Python

import requests

res = requests.get(
    "https://alamat-server/api/v1/earthquakes",
    params={"days": 7},
    headers={"X-API-Key": "KUNCI_ANDA"},
    timeout=30,
)
res.raise_for_status()
for f in res.json()["features"]:
    print(f["properties"]["magnitude"], f["properties"]["wilayah"])

Notifikasi langsung

/stream mengirim notifikasi saat terjadi lewat Server-Sent Events: gempa BMKG baru, perubahan level gunung api, dan peringatan dini cuaca baru. Sambungannya dibiarkan terbuka, dan satu sambungan dihitung satu permintaan. 

curl -N -H "X-API-Key: KUNCI_ANDA" "https://alamat-server/api/v1/stream"
const res = await fetch('https://alamat-server/api/v1/stream', {
  headers: { 'X-API-Key': 'KUNCI_ANDA' },
});
const decoder = new TextDecoder();
let sisa = '';
for await (const potongan of res.body) {
  const blok = (sisa + decoder.decode(potongan, { stream: true })).split('\n\n');
  sisa = blok.pop();
  for (const b of blok) {
    const data = b.split('\n').find((baris) => baris.startsWith('data: '));
    if (data) console.log(JSON.parse(data.slice(6))); // { id, kind, level, title, body, lat, lon, created_at, ... }
  }
}

Bila sambungan putus, sambung lagi dengan header Last-Event-ID berisi id notifikasi terakhir. Notifikasi yang terlewat dikirim ulang, paling lama 24 jam. EventSource di browser tidak bisa mengirim header, jadi pakai fetch seperti contoh di atas.

Kuota dan galat

  • Kuota 5.000 permintaan per kunci per hari, berganti pukul 07.00 WIB. Sisanya ada di header X-RateLimit-Remaining tiap jawaban.
  • Satu email paling banyak punya 3 kunci aktif.
  • Galat selalu berbentuk {"error": "penjelasan"}.
Status Artinya
400 Isian pendaftaran kunci kurang atau salah.
401 Kunci tidak dikirim, atau tidak dikenal.
403 Kunci sudah dicabut.
404 Endpoint tidak ada di API ini.
409 Email itu sudah punya jumlah kunci aktif terbanyak.
429 Kuota harian habis, lebih dari 300 permintaan per menit dari satu jaringan, atau lebih dari 3 aliran notifikasi dibuka sekaligus. Untuk dua yang pertama, header Retry-After memberi tahu berapa detik lagi boleh mencoba.

Ketentuan pakai

  1. Sebutkan sumbernya. Cantumkan lembaga di kolom "Sumber data" tiap endpoint, karena datanya milik mereka. SIGAP hanya mengumpulkan dan menyajikannya.
  2. Untuk riset, pendidikan, dan layanan publik nonkomersial. Sebagian sumber tidak mengizinkan pemakaian komersial lewat layanan gratisnya. Untuk pemakaian lain, tanyakan dulu lewat halaman isu repositori.
  3. Bukan peringatan resmi. Jangan menjadikan data ini satu-satunya dasar keputusan keselamatan, dan jangan menampilkannya seolah-olah peringatan dari BMKG, PVMBG, atau BNPB.
  4. Tanpa jaminan ketersediaan. Ini server riset mahasiswa; layanan bisa lambat, berubah, atau berhenti.
  5. Kunci bisa dicabut bila dipakai untuk membebani server atau melanggar ketentuan ini.
  6. Data pendaftar. Nama, email, dan tujuan pemakaian disimpan untuk mengelola kunci dan tidak dibagikan. Jumlah permintaan tiap kunci dicatat per hari.
